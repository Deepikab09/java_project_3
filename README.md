# Student Management System – Java

A console-based project for Module 02: Methods, Collections & Exceptions.

## Features
- Add, view, search, update and delete student records.
- Stores records using ArrayList.
- Uses HashMap for student ID lookup and HashSet to prevent duplicate emails.
- Validates input and handles exceptions.
- Saves and loads records using a text file (`students.txt`).

## Requirements
Java JDK 17 or later.

## Run the project
Open a terminal in this folder and execute:

```bash
javac -d out src/main/java/StudentManagementSystem.java
java -cp out StudentManagementSystem
```

## Concepts demonstrated
- Methods, parameter passing and method overloading.
- Local variables, instance variables and scope.
- ArrayList, HashMap and HashSet.
- try-catch, throw, throws and a custom exception.
- File reading and writing with try-with-resources.
